# go-kit

A collection of small, reusable Go packages used across OFKM projects.

Each package is self-contained and depends only on the Go standard library, so
you can import just the ones you need.

## Packages

- [`validation`](./validation) - Validating and normalizing untrusted user input, such as file paths.

## Installation

```sh
go get go.ofkm.dev/kit
```

Requires Go 1.26 or later. Documentation for each package is available on
[pkg.go.dev](https://pkg.go.dev/go.ofkm.dev/kit).
